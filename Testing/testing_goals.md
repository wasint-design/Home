# Project Goals (Business)

1. Reduce new user churn caused by app complexity to convert more new users and grow our demand source
2. Increase campaign / partner participation rate by ensuring users notice and understand campaigns
3. Increase demand by keeping users in the app through lower friction, reducing opportunities for users to switch to competitors
4. Reduce cancellations caused by user error (location / service / pax) to cut sunk costs and reduce user frustration

# Testing Goals (Usability)

1. New users can complete their first booking end-to-end without assistance and understand MuvMi's service model (pickup points, shared ride, zones) before confirming → supports Project goal 1
2. Existing users (Casual/Recurring) can complete their regular flow faster and more easily than the current flow → supports Project goal 3
3. Users notice and understand promotions / hop-points / suggested places / upsells without disruption to their main task → supports Project goals 2, 3
4. Users select the correct location, service, and pax count on the first attempt and fully understand the confirm screen before submitting → supports Project goal 4
5. Users who encounter an edge case (out of zone / no vehicle available) understand the cause and know what to do next → supports Project goals 1, 4

# Success Metrics

* New User complete requesting flow ≥ 90% (unassisted)
* SEQ ≥ 5.5/7 per task (How easy the task was from 1-7)
* Repeat trip: taps + time-to-submit vs. current flow (recurring users run the task twice to separate learnability dip from genuine design issues)
* Awareness: recall + comprehension after the main task (what did they see, what does the campaign offer, what do they need to do)
* Error task: users encounter an edge case (out of zone / no vehicle available) and understand the cause and what to do next

# User Target Goals (per User Type)

## New User

* Users can complete their requesting flow without any issues, building confidence to book again
* Users are aware they can explore suggested places, opening the door to future trips
* Users are aware of promotions, travel, and private upsells from their very first session

## Casual User

* Users accomplish their regular flow and understand how the new design works effortlessly
* Users can travel to past locations more easily from the homepage, making rebooking a habit
* Users are aware of promotions and suggested locations or partners they can explore
* Users explore more campaign locations, driving traffic to partner spots

## Recurring User

* Everyday users can travel faster and more effortlessly, keeping their daily routine friction-free
* Users can explore new locations more easily, expanding trips beyond their usual routes
* Users are aware of promotions and suggested locations or partners they can explore

## Travel User

* Users can explore more tourist attractions and places to travel, positioning MuvMi as a travel companion
* Users can search for their destination more easily, reducing drop-offs before booking
* Users can upgrade to a private tour more easily, unlocking higher revenue per trip
